### xerces-opt —— 面向 GCC 编译器的 Xerces-C++ 性能优化实验库

本项目致力于从编译器视角探索并提升 Xerces-C++ XML Parser 在 GCC 平台下的性能表现。

- 提取并精简核心源码模块，隔离性能瓶颈。
- 开发 GCC 插件与补丁，实现优化。
- 辅以分析脚本、性能度量工具与基准测试，形成「编译-分析-优化」闭环研究体系。

核心内容：

1. Xerces-C++ 代码切片：用于性能分析的模块化代码片段
2. GCC 插件与补丁：可注入编译器行为的优化扩展
3. 辅助工具：性能监控、调用图分析、构建脚本等
4. 基准测试：对比原生库与优化后版本在不同 workload 下的表现

适用对象：

- 编译器开发者
- 性能调优工程师
- 对 XML 解析器底层优化感兴趣的研究者

构建与运行：

xerces 库测试脚本构建 `test/test-xercese/build-xercese.rkt`
